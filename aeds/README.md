# AEDS - Algoritmos e Estruturas de Dados

## Objetivo

Reunir modulos educacionais voltados para o estudo de AEDS II. Os modulos
abordam estruturas de dados, algoritmos de manipulacao, complexidade e
propriedades, sempre de forma interativa e voltada para prova.

## Modulo atual

### [aeds-2/](aeds-2/) - AEDS II

**Estado:** modulo principal de AEDS no momento, organizado por prova
(Prova 1, Prova 2, Prova 3 e Reavaliacao cumulativa).

Modulo interativo para estudo de estruturas de dados, com visualizacoes,
simulacoes, exercicios de codigo e atividades conceituais. A experiencia atual
combina selecao de prova, oficina de codigo, treino continuo, caderno
adaptativo de erros, visualizacoes de estruturas e simulado.

Dominios cobertos (ver [`aeds-2/docs/content-map.md`](aeds-2/docs/content-map.md)
para o mapeamento completo por prova):

- Doidona;
- Arvore TRIE;
- Arvore AVL;
- Arvore normal/binaria;
- Somatorios;
- Algoritmos de ordenacao;
- Estruturas lineares (lista, fila, pilha, matriz), estaticas e flexiveis.

As instrucoes para instalar, executar, testar e gerar build ficam no README do
modulo atual: [`aeds-2/README.md`](aeds-2/README.md).

Nesta materia, `aeds/materiais/` pode conter slides, listas, imagens e outros
materiais de referencia que o dono do repositorio decidiu manter versionados.

que e ignorada pelo Git.
